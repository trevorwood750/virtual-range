VIRTUAL RANGE IPHONE PROTOTYPE 0.1

This prototype displays a target and tests rear-camera permission. It does NOT detect laser pulses or score shots.

Camera access on iPhone requires HTTPS. Opening index.html directly from the Files app will not enable camera access.

To install:
1. Publish the contents of this folder to a static HTTPS host (such as GitHub Pages).
2. Open the HTTPS site in Safari on your iPhone.
3. Tap Share > Add to Home Screen.
4. Open Virtual Range from the Home Screen and tap Start camera.
5. Allow camera access when asked.

The camera preview is not recorded or uploaded by this prototype.
